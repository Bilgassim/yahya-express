## 🚀 Fonctionnalités du Site
- **Landing Page (`index.html`) :**
  - Section Hero avec slogan et boutons d'appel direct & commande.
  - Section Valeurs : **Rapidité** (*À temps, à chaque fois*), **Sécurité** (*Vos colis, notre priorité*), **Confiance** (*Au service de nos clients*).
  - Ancrage local avec monuments emblématiques de Berkane (*Rond-point de l'Orange*, *I ❤️ Berkane*).
  - Présentation des 3 services phares (**Colis**, **Courses**, **Partout / Restauration**).
  - **Simulateur interactif de tarif de livraison (en Dirhams)** avec pont de commande WhatsApp.
  - **Galerie Médias interactive avec Lightbox plein écran** (Photos réelles, flotte de motos, restaurants partenaires et vidéos).
  - Avis clients et restaurateurs de Berkane.
  - Bannière d'appel d'urgence et Foire Aux Questions (FAQ accordéon).
- **Page Services (`services.html`) :**
  - Fiches détaillées des prestations.
  - Processus de commande en 3 étapes simples.
  - Solutions pour commerçants et e-commerçants (gestion du Cash on Delivery).
- **Page Contact & Commande (`contact.html`) :**
  - Coordonnées complètes et carte de couverture.
  - Formulaire interactif qui pré-remplit un message WhatsApp prêt à être envoyé.
- **Boutons Flottants :** Appel direct 1-clic et badge flottant WhatsApp avec effet pulsation.

## 🌐 Déploiement GitHub Pages
Ce projet est configuré avec un workflow automatisé GitHub Actions (`.github/workflows/deploy.yml`).

### Activer GitHub Pages sur le dépôt :
1. Rendez-vous sur votre dépôt GitHub : [https://github.com/Bilgassim/yahya-express](https://github.com/Bilgassim/yahya-express)
2. Cliquez sur **Settings** > **Pages** (dans le menu de gauche).
3. Dans la section **Build and deployment** :
   - Sous **Source**, sélectionnez **GitHub Actions** (ou `Deploy from a branch` > branch `main` / root `/`).
4. Votre site sera accessible publiquement à l'adresse :
   👉 **`https://bilgassim.github.io/yahya-express/`**
